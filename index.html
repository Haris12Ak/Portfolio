    Full-Stack Application | ASP.NET Core Web API, C#, Angular, SQL Server

    ◾ Vehicle inspection and service history
    ◾ Service and spare parts management
    ◾ Inventory and supplier management
    ◾ Invoice and payment management
    ◾ Work order status history
    ◾ Notifications and service updates
    ◾ Company-specific business settings and pricing
    ◾ Dashboard with operational and financial statistics
    ◾ Customer service history and vehicle records

    FreshMarket Management System

    Full-Stack Application | ASP.NET Core Web API, C#, Angular, SQL Server

    Fresh Market is a web application designed to manage the purchase of forest products for companies. The application is intended for company owners and their clients. The idea behind the app is that, as a company owner, after successfully registering your company and user profile, you have the ability to manage your clients (add new clients, where each client receives an email with login credentials to access the application and view their purchases), products (set product prices, edit, delete), purchases (add purchases for clients and view amounts and prices, edit, delete), and news (add updates for clients, with real-time notifications using SignalR, edit, delete).
    The client role includes viewing the products the company purchases, accessing purchase details and total income, browsing news, and viewing a dashboard with key purchase-related information.

    Authorization: Keycloak Auth
    Technologies: ASP.NET Core Web API, Entity Framework Core, SQL Server, RabbitMQ, SignalR, SendGrid, Docker, Angular

    Air Conditioner Management System

    IoT Project
    Monitoring and Control

    IoT (Internet of Things) project for simulating air conditioner management using a NodeMcu controller and sensors (temperature and movement). The idea of the project is to simulate air conditioner control through a web application, where sensors read the current room temperature and a motion sensor detects the number of people in the room. Based on the data received from the sensors, the controller adjusts the air conditioner to the optimal temperature set by the user. The values read from the sensors are stored in the Firebase Realtime Database.

    Technologies: HTML, CSS, JavaScript, Arduino, Firabase
    Components: NodeMcu ESP8266, motion sensor, temperature sensor
